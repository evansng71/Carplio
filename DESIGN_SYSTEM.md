# Design system

## Direction

Outil premium exploitation — **bleu nuit / blanc cassé / bleu action**, sans imitation d’interfaces existantes.

## Tokens

| Token | Valeur |
|---|---|
| Night | `#0B1F33` |
| Cream | `#F7F5F1` |
| Action | `#1B6CA8` |
| OK | `#1F7A4D` |
| Warn | `#C47A1A` |
| Danger | `#B42318` |

Typo : **Manrope** (`next/font`).

## Composants

- `.btn-primary` / `.btn-ghost` / `.btn-danger`  
- `.card`, `.input`, `.label`  
- Shell : sidebar pliable navy, recherche globale, sélecteur société/dépôt  

## Planning

Gantt quatorzaine : lignes conducteurs, blocs proportionnels, bleu=publié, orange=brouillon, gris=repos.
